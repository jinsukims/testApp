# 할 일 관리

브라우저만 있으면 동작하는 할 일(Todo) 관리 앱입니다.
순수 HTML · CSS · JavaScript로 만들었고, 설치나 빌드 없이 바로 실행할 수 있습니다.
데이터는 브라우저의 localStorage에 저장되어 새로고침하거나 브라우저를 다시 열어도 유지됩니다.

## 실행 방법

### 방법 1. index.html 직접 열기
`index.html` 파일을 더블클릭하거나 브라우저 창으로 끌어다 놓습니다.

### 방법 2. VS Code Live Server (권장)
1. VS Code에서 확장 프로그램 **Live Server**를 설치합니다.
2. 이 폴더를 VS Code로 엽니다.
3. `index.html`에서 마우스 오른쪽 버튼 → **Open with Live Server**를 누릅니다.
4. 브라우저에서 `http://127.0.0.1:5500/index.html` 같은 주소로 열립니다.

> ⚠️ **항상 같은 주소로 열어야 데이터가 이어집니다.**
> localStorage는 주소(출처)별로 따로 저장됩니다. `file:///...`로 연 것과 `http://127.0.0.1:5500`으로 연 것은 서로 다른 저장소이고,
> Live Server의 포트 번호가 바뀌어도(예: 5500 → 5501) 다른 저장소가 됩니다.
> 사생활 보호(시크릿) 창에서는 창을 닫으면 데이터가 사라집니다.

## 기능

- **추가**: 제목(1~100자) + 카테고리(업무/개인/공부)를 입력하고 [추가] 또는 Enter
- **완료 체크**: 체크박스로 완료/미완료 전환, 완료 항목은 취소선 + 흐리게 표시
- **수정**: [수정] 버튼 또는 제목 더블클릭 → 그 자리에서 제목·카테고리 수정 (Enter 저장, Esc 취소)
- **삭제**: [삭제] 버튼 → 확인 후 삭제, [완료 항목 지우기]로 완료 항목 일괄 삭제
- **카테고리 배지**: 업무(파랑) · 개인(초록) · 공부(보라), 마지막으로 고른 카테고리를 기억
- **자동 카테고리 분류**: 제목을 입력하면 키워드(예: 회의·보고서 → 업무, 운동·장보기 → 개인, 시험·토익 → 공부)를 보고 카테고리를 자동 선택하고 "자동 분류: ○○"로 안내. 직접 카테고리를 고르면 그 선택을 우선. 키워드 목록은 `app.js`의 `CATEGORY_KEYWORDS`에서 바꿀 수 있음
- **진행률**: 전체 완료율(예: "58% · 12개 중 7개 완료"), 진행 막대, 카테고리별 완료/전체 수
- **필터**: 카테고리(전체/업무/개인/공부) × 상태(전체/진행 중/완료) 조합, 새로고침 후에도 유지
- **정렬**: 미완료 항목이 위, 완료 항목이 아래, 같은 그룹 안에서는 최신 항목이 위
- **남은 할 일 개수** 표시
- **저장 오류 안내**: 데이터 손상 시 백업 후 빈 목록으로 시작, 저장 불가·용량 초과 시 상단 안내
- **반응형**: 360px(모바일) ~ 1280px(데스크톱), 모바일에서는 입력 영역 세로 배치 + 44px 이상 터치 영역
- **접근성**: 키보드(Tab · Enter · Space · Esc)만으로 모든 조작 가능, 항목별 aria-label, 진행률 변화 음성 안내(aria-live)

## 파일 구조

```
.
├── index.html   # 화면 구조
├── style.css    # 스타일 (상단에 색상 CSS 변수, 하단에 모바일 미디어 쿼리)
├── app.js       # 상태 관리 · 화면 그리기 · 저장 로직
└── README.md
```

## 데이터 저장 위치 (localStorage)

| 키 | 내용 |
| --- | --- |
| `todoApp.tasks` | 할 일 배열(JSON). 각 항목: `{ id, title, category, completed, createdAt, updatedAt }` |
| `todoApp.version` | 데이터 구조 버전 (현재 `1`) |
| `todoApp.settings` | 설정(JSON): `{ lastCategory, filterCategory, filterStatus }` |
| `todoApp.backup` | `todoApp.tasks`가 손상되었을 때 보관한 원본 문자열 (손상 시에만 생성) |

개발자 도구(F12) → **Application** 탭 → **Local Storage**에서 값을 직접 확인할 수 있습니다.
